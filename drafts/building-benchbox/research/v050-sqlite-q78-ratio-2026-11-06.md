# Evidence: TPC-DS Q78 ratio on SQLite, BenchBox 0.4.2 vs 0.5.0

Source for `images/v050_sqlite_q78_ratio.png` in the v0.5.0 release post.
Captured 2026-11-06 on macOS, SQLite 3.54.0, Python 3.12.15.

## Method

Both releases were asked for the SQL they would run, with `--dry-run`,
which saves the same SQL a real run uses. The two `query_78.sql` files were
then executed with the `sqlite3` CLI against one database that BenchBox
0.5.0 had loaded at scale factor 0.01, so the loader cannot account for the
difference.

```bash
for v in 0.4.2 0.5.0; do
  uvx --with pandas --from "benchbox==$v" benchbox run --platform sqlite \
    --benchmark tpcds --scale 0.01 --dry-run ./tpcds-$v --non-interactive
done
uvx --with pandas --from "benchbox==0.5.0" benchbox run --platform sqlite \
  --benchmark tpcds --scale 0.01 --queries 78 --phases power --non-interactive \
  --output ./run-new
DB=benchmark_runs/databases/tpcds_sf001/tpcds_sf001_notuning_noconstraints.sqlite
sqlite3 "$DB" < tpcds-0.4.2/*/query_78.sql | head -4
sqlite3 "$DB" < tpcds-0.5.0/*/query_78.sql | head -4
```

`--with pandas` is needed because 0.4.2's dry run imports every benchmark
and fails without it.

## Generated SQL (ratio column only)

0.4.2, public `sqlglot`:

```sql
ROUND("ss_qty" / (COALESCE("ws_qty", 0) + COALESCE("cs_qty", 0)), 2) AS "ratio"
```

0.5.0, bundled `benchbox-sqlglot` 30.29.0.1:

```sql
ROUND(CAST("ss_qty" AS REAL) / (COALESCE("ws_qty", 0) + COALESCE("cs_qty", 0)), 2) AS "ratio"
```

## Other SQLite differences seen in the same sweep

Of the 99 TPC-DS files, 57 differ between the two releases. Executed
against the same database, the 0.4.2 SQL fails outright for Q16, Q94 and
Q95 (`INTERVAL '60' DAY`), Q17 (`STDDEV_SAMP`), Q87 (`EXCEPT` placement)
and the `ROLLUP`/`GROUPING` queries Q5, Q18, Q22, Q27, Q36, Q67, Q70, Q77,
Q80 and Q86. Q21 returns 4 rows on 0.4.2 and 7 on 0.5.0 for the same
integer-division reason as Q78. Q93 differs because its reason-text
parameter changed, not its translation. TPC-H on SQLite differs only in Q1
(date arithmetic spelling) and Q8 (a defensive `CAST AS REAL`); neither
changes the answer at scale factor 0.01.
