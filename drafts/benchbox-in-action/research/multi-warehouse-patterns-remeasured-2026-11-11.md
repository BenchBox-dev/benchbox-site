# Evidence: multi-warehouse detection patterns, remeasured across engine versions

Source for the tables in the draft
`drafts/benchbox-in-action/drafts/06-platform-specific-optimization-patterns.md`.
Captured 2026-11-11 on an Apple M4 (10 cores, 16 GB RAM), macOS 27.0.1,
Python 3.12, OpenJDK 21 for PySpark. It supersedes the February 2026
measurements in `platform-optimization-patterns.md`, which were taken on
an Apple M1 Mac Mini with Polars 1.37.1, DataFusion 51.0.0 and PySpark
4.1.1 and are kept as the record of the original finding.

## Caveat: the workstation was shared

Other jobs ran on the machine throughout. The 1-minute load average at
the start of each engine run was between 24 and 57 in the first counted
pass and between 13 and 19 in the second, on 10 cores. Two earlier attempts
under load averages of up to 113 were discarded. Because of this:

- Every table reports the best (minimum) wall time over all timed runs
  in the two counted passes, then the median of the quieter second pass.
  The best time is the statistic least inflated by other jobs.
- The patterns were interleaved inside each iteration, so the patterns
  of one engine version saw the same conditions. Ratios between patterns
  of one engine version are the reliable quantity. Of the 350 ratios of
  a pattern to `n_unique`, the two passes differed by a median of 4%.
  90% agreed within 15% and all but one within 33%. The exception is
  DuckDB 2.0.0 `exists` on SF10 `web_sales` (14.2x in the first pass,
  6.2x in the second).
- Absolute times, and comparisons of absolute times between versions,
  carry more error than the ratios. Rerun on an idle machine before
  quoting an absolute time as an engine's speed.

The synthetic data repeats the February design: 90% of orders have one
line and 10% have two to four lines, each from a different one of 20
warehouses. The TPC-DS data is the `order_number` and `warehouse_sk`
columns of `catalog_sales` and `web_sales` as generated by DuckDB's
`tpcds` extension (`CALL dsdgen(sf=...)`, DuckDB 1.5.6). In the TPC-DS
data nearly every order ships from more than one warehouse, and an order
has 4 to 7 distinct warehouses on average, so the self-join emits 3.3 to
6.3 times as many rows as the pairs it reads.

## Method

Each engine version ran in its own process, started with
`uv run --no-project --python 3.12 --with <package>==<version>`. Data was
loaded into memory before timing: a Polars `DataFrame`, a DuckDB table, a
cached DataFusion `DataFrame`, a cached Spark `DataFrame`. One iteration
ran every pattern once, in a fixed order, and materialized the result as
an Arrow table. The first two iterations were discarded. The Polars,
DuckDB and DataFusion runs then repeated for at least 9 iterations and
until 20 to 25 seconds had passed for that dataset (300 iterations at
most). PySpark ran 9 timed iterations. Engines used their default thread
counts; Spark ran `local[*]` with 6 GB driver memory, 200 shuffle
partitions and adaptive execution on (both defaults).

Patterns:

- `exists` (DuckDB only): the form in the TPC-DS query text.
- `self_join`: de-duplicate (order, warehouse) pairs, join the pairs to
  themselves on the order, keep pairs with different warehouses,
  de-duplicate the order numbers.
- `n_unique`: group by order, count distinct warehouses, keep counts
  above 1.
- `min_max`: group by order, keep groups whose minimum and maximum
  warehouse differ.
- `n_unique_nonnull` (Polars only): `n_unique` after `drop_nulls()`.

Polars ran each pattern on both engines, `collect(engine="in-memory")`
and `collect(engine="streaming")`. A plain `collect()` uses the in-memory
engine in Polars 1.x and the streaming engine from 2.0.

### Answers

Every pattern on every engine and version returned the same order
numbers (row count and sum of order numbers compared), with one
exception. Polars `n_unique()` counts NULL as a value, so on
`catalog_sales` it also returned orders with one warehouse plus a NULL
warehouse: 159,871 orders against 159,852 at SF1, and 1,599,816 against
1,599,778 at SF10. `n_unique_nonnull` returned the common answer.

Data generator (`gen.py`), run once with DuckDB 1.5.6, NumPy and PyArrow:

```python
import sys
from pathlib import Path

import duckdb
import numpy as np
import pyarrow as pa
import pyarrow.parquet as pq

OUT = Path(sys.argv[1])
SCALES = {"10K": 10_000, "50K": 50_000, "100K": 100_000, "250K": 250_000, "500K": 500_000, "1M": 1_000_000}
WAREHOUSES = 20


def synthetic(n_orders: int, seed: int = 42) -> pa.Table:
    rng = np.random.default_rng(seed)
    multi = rng.random(n_orders) < 0.10
    lines = np.where(multi, rng.integers(2, 5, n_orders), 1)
    order = np.repeat(np.arange(1, n_orders + 1, dtype=np.int64), lines)
    first = rng.integers(1, WAREHOUSES + 1, n_orders)
    offset = np.concatenate([np.arange(k) for k in lines])
    wh = (np.repeat(first, lines) - 1 + offset) % WAREHOUSES + 1
    perm = rng.permutation(len(order))
    return pa.table({"order_number": order[perm], "warehouse_sk": wh[perm].astype(np.int64)})


for name, n in SCALES.items():
    t = synthetic(n)
    pq.write_table(t, OUT / f"synthetic_{name}.parquet")
    print(name, t.num_rows)

for sf in (1, 10):
    con = duckdb.connect()
    con.execute("INSTALL tpcds; LOAD tpcds")
    con.execute(f"CALL dsdgen(sf={sf})")
    for table, prefix in (("catalog_sales", "cs"), ("web_sales", "ws")):
        path = OUT / f"tpcds_sf{sf}_{table}.parquet"
        con.execute(
            f"COPY (SELECT {prefix}_order_number AS order_number, {prefix}_warehouse_sk AS warehouse_sk "
            f"FROM {table}) TO '{path}' (FORMAT parquet)"
        )
        print(
            sf,
            table,
            con.execute(
                f"SELECT count(*), count(DISTINCT order_number), count(*) FILTER (warehouse_sk IS NULL), "
                f"count(DISTINCT warehouse_sk) FROM '{path}'"
            ).fetchone(),
        )
    con.close()
```

```python
def polars_engine():
    import polars as pl

    version = pl.__version__

    def load(path):
        return pl.read_parquet(path).lazy()

    def self_join(lf):
        ow = lf.select(["order_number", "warehouse_sk"]).unique()
        return (
            ow.join(ow.rename({"warehouse_sk": "wh2"}), on="order_number")
            .filter(pl.col("warehouse_sk") != pl.col("wh2"))
            .select("order_number")
            .unique()
        )

    def n_unique(lf):
        return (
            lf.group_by("order_number")
            .agg(pl.col("warehouse_sk").n_unique().alias("n"))
            .filter(pl.col("n") > 1)
            .select("order_number")
        )

    def n_unique_nonnull(lf):
        return (
            lf.group_by("order_number")
            .agg(pl.col("warehouse_sk").drop_nulls().n_unique().alias("n"))
            .filter(pl.col("n") > 1)
            .select("order_number")
        )

    def min_max(lf):
        return (
            lf.group_by("order_number")
            .agg(pl.col("warehouse_sk").min().alias("lo"), pl.col("warehouse_sk").max().alias("hi"))
            .filter(pl.col("lo") != pl.col("hi"))
            .select("order_number")
        )

    patterns = {}
    for eng in ("in-memory", "streaming"):
        for name, fn in (
            ("self_join", self_join),
            ("n_unique", n_unique),
            ("n_unique_nonnull", n_unique_nonnull),
            ("min_max", min_max),
        ):
            patterns[f"{name}@{eng}"] = (
                lambda lf, fn=fn, eng=eng: fn(lf).collect(engine=eng).to_arrow(),
                lambda lf, fn=fn, eng=eng: fn(lf).explain(engine=eng)
                if eng == "streaming"
                else fn(lf).explain(),
            )
    return version, load, patterns


def duckdb_engine():
    import duckdb

    version = duckdb.__version__
    con = duckdb.connect()

    def load(path):
        con.execute(f"CREATE OR REPLACE TABLE t AS SELECT * FROM '{path}'")
        return con

    sql = {
        "exists": "SELECT DISTINCT a.order_number FROM t a WHERE EXISTS (SELECT * FROM t b "
        "WHERE a.order_number = b.order_number AND a.warehouse_sk <> b.warehouse_sk)",
        "self_join": "WITH ow AS (SELECT DISTINCT order_number, warehouse_sk FROM t) "
        "SELECT DISTINCT a.order_number FROM ow a JOIN ow b USING (order_number) "
        "WHERE a.warehouse_sk <> b.warehouse_sk",
        "n_unique": "SELECT order_number FROM t GROUP BY order_number HAVING count(DISTINCT warehouse_sk) > 1",
        "min_max": "SELECT order_number FROM t GROUP BY order_number HAVING min(warehouse_sk) <> max(warehouse_sk)",
    }

    def run(q):
        return lambda c: c.sql(q).to_arrow_table()

    def plan(q):
        return lambda c: "\n".join(r[1] for r in c.execute("EXPLAIN " + q).fetchall())

    return version, load, {k: (run(q), plan(q)) for k, q in sql.items()}


def datafusion_engine():
    import datafusion
    import pyarrow as pa
    from datafusion import SessionContext, col, lit
    from datafusion import functions as F

    version = datafusion.__version__
    ctx = SessionContext()

    def load(path):
        return ctx.read_parquet(str(path)).cache()

    def self_join(df):
        ow = df.select(col("order_number"), col("warehouse_sk")).distinct()
        other = ow.select(col("order_number").alias("o2"), col("warehouse_sk").alias("wh2"))
        return (
            ow.join(other, left_on="order_number", right_on="o2", how="inner")
            .filter(col("warehouse_sk") != col("wh2"))
            .select(col("order_number"))
            .distinct()
        )

    def n_unique(df):
        return (
            df.aggregate([col("order_number")], [F.count(col("warehouse_sk"), distinct=True).alias("n")])
            .filter(col("n") > lit(1))
            .select(col("order_number"))
        )

    def min_max(df):
        return (
            df.aggregate(
                [col("order_number")],
                [F.min(col("warehouse_sk")).alias("lo"), F.max(col("warehouse_sk")).alias("hi")],
            )
            .filter(col("lo") != col("hi"))
            .select(col("order_number"))
        )

    def run(fn):
        return lambda df: pa.Table.from_batches(fn(df).collect(), schema=pa.schema([("order_number", pa.int64())]))

    def plan(fn):
        return lambda df: fn(df).execution_plan().display_indent()

    return version, load, {
        k: (run(f), plan(f)) for k, f in (("self_join", self_join), ("n_unique", n_unique), ("min_max", min_max))
    }


def pyspark_engine():
    import pyspark
    from pyspark.sql import SparkSession
    from pyspark.sql import functions as F

    version = pyspark.__version__
    spark = (
        SparkSession.builder.master("local[*]")
        .config("spark.driver.memory", "6g")
        .config("spark.ui.enabled", "false")
        .config("spark.sql.execution.arrow.pyspark.enabled", "true")
        .getOrCreate()
    )
    spark.sparkContext.setLogLevel("ERROR")
    state = {}

    def load(path):
        if "df" in state:
            state["df"].unpersist()
        df = spark.read.parquet(str(path)).cache()
        df.count()
        state["df"] = df
        return df

    def self_join(df):
        ow = df.select("order_number", "warehouse_sk").distinct()
        other = ow.withColumnRenamed("warehouse_sk", "wh2")
        return (
            ow.join(other, on="order_number")
            .filter(F.col("warehouse_sk") != F.col("wh2"))
            .select("order_number")
            .distinct()
        )

    def n_unique(df):
        return (
            df.groupBy("order_number")
            .agg(F.countDistinct("warehouse_sk").alias("n"))
            .filter(F.col("n") > 1)
            .select("order_number")
        )

    def min_max(df):
        return (
            df.groupBy("order_number")
            .agg(F.min("warehouse_sk").alias("lo"), F.max("warehouse_sk").alias("hi"))
            .filter(F.col("lo") != F.col("hi"))
            .select("order_number")
        )

    def run(fn):
        return lambda df: fn(df).toArrow()

    def plan(fn):
        return lambda df: fn(df)._jdf.queryExecution().executedPlan().toString()

    return version, load, {
        k: (run(f), plan(f)) for k, f in (("self_join", self_join), ("n_unique", n_unique), ("min_max", min_max))
    }
```
